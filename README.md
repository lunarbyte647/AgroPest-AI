# AgroPest AI 🌱

An AI-powered crop disease classification and health monitoring system developed using YOLOv8 and Flask.

## Features

- Crop disease classification
- Crop health monitoring
- Disease confidence scoring
- Recommendation generation
- Interactive Flask web interface
- Support for:
  - Cashew
  - Cassava
  - Maize
  - Tomato

## Technologies Used

- Python
- Flask
- YOLOv8 Classification
- HTML
- CSS
- Git & GitHub

## Project Workflow

Upload Crop Image
↓
YOLOv8 Classification
↓
Disease Prediction
↓
Health Analysis
↓
Recommendations
